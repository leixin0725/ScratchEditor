# 阶段 4：扩展 UI 与配置管理验收报告

验收时间：2026-08-02（Asia/Shanghai）

## 结论

阶段 4 已通过。程序现已具备延迟加载的轻量设置页、深浅主题、编辑字体与字号配置、可关闭的轻量过渡动画，以及集中式 INI 配置管理。阶段 3 和阶段 2 完整功能回归、阶段 1 全量性能回归、独立部署验证均通过。按更新后的迁移文档，本阶段未实现历史草稿、标签页、固定草稿、多光标、插件或 LSP，也未恢复已由用户明确排除的 Markdown 预览。

## 实现范围

- 新增集中式 `AppSettings` 配置层，统一管理窗口几何、快捷键、主题、编辑字体、字号和动画开关。
- 正式配置使用 `QStandardPaths::AppConfigLocation/settings.ini`；测试支持独立 `SCRATCHEDITOR_SETTINGS_FILE`，不会污染用户配置。
- 配置文件包含 schema 版本；首次使用新的正式配置文件时，会从旧的 Windows Native Settings 迁移窗口几何和快捷键，旧数据仍保留。
- 设置页通过 QML `Loader` 首次调用时创建，关闭后释放；默认快捷键为 `Ctrl+,`，也可从命令面板打开。
- 支持 `dark` / `light` 两套完整界面配色；Markdown 高亮格式与 Win32 DWM 暗色属性同步切换。
- 编辑字体必须是系统已安装字体；字号限制为 9–24。默认仍为 `Microsoft YaHei UI`、13 pt。
- 主题、字体、字号、动画、窗口几何和自定义快捷键均跨进程持久化，并提供恢复默认外观。
- QML 使用 `Behavior`、`ColorAnimation` 和 `NumberAnimation` 实现面板与颜色过渡；窗口唤出/关闭由 C++ 并行动画同步处理透明度和几何形变。关闭动画后所有过渡时长为 0。未加入循环动画或空闲轮询。

## 后续窗口交互与动画回归补充

该补充发生在上述阶段 4 历史基线之后，对应提交 `0233beb` 与 `423fe6e`：

- 无边框窗口现在支持四边及四角原生缩放；最外侧 8 px 保留缩放命中，顶部和其余三侧的内层边框可拖动窗口。
- 编辑缓冲区使用独立的表面颜色，与窗口背景形成轻微层次区分；深浅主题均保留该差异。
- 120 ms 唤出/关闭窗口动画由 C++ `QParallelAnimationGroup` 和两个 `QVariantAnimation` 同步驱动透明度与居中 98% 几何形变。
- 动画复用时先屏蔽 `valueChanged` 并重置时间线，再替换起止值，避免已结束动画同步发出新终值造成“先缩小、再回弹”的单帧脉冲。
- Windows 隐藏窗口前通过 `DwmFlush` 提交完全透明帧，避免原生取消映射时重放上一帧表面。
- 阶段 4 自动验收新增窗口交互/配色检查及 20 轮唤出/关闭压力回归，验证隐藏态尺寸稳定、重新唤出恢复记录几何且动画准备阶段不改变窗口状态。
- 用户实机确认修复有效；约 150–160 FPS 的系统实际像素抽样连续 3 轮未观察到缩小后回弹。
