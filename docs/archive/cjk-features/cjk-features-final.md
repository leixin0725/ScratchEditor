# ScratchEditor CJK 功能最终需求清单

**权威顺序：本清单 > `cjk-features-fix-plan.md` > 原始需求 > 历史实施计划。** 历史实施计划只作实现参考；冲突内容全部由本清单覆盖。

## 1. 字符分类

```regex
CJK :=
[\u3400-\u4DBF\u4E00-\u9FFF
 \u3040-\u309F\u30A0-\u30FF\u31F0-\u31FF
 \u1100-\u11FF\u3130-\u318F\uAC00-\uD7AF]

ASCII 字母数字 := [A-Za-z0-9]
```

不扩展到汉字扩展 B、非 ASCII 字母或全角标点。

## 2. 键盘标点转换

仅对**无 Ctrl/Alt/Meta 的直接键盘输入**生效；IME commit 和粘贴不执行标点转换。

```text
CJK,  → CJK，
CJK.  → CJK。
CJK:  → CJK：
CJK?  → CJK？
CJK!  → CJK！
CJK;  → CJK；
CJK)  → CJK）
CJK(  → CJK（|）
，,    → ，，
。.    → 。。
CJK-- → CJK——
```

`)` 应先尝试跳过已有 `）`；失败后才按 CJK 规则转换。

### 省略号最终规则

**只转换以下三种：**

```text
...  → ……
。。。 → ……
。。. → ……
```

其他混合形式均不转换，例如：

```text
.。.  → .。.
..。  → ..。
。.。  → 。.。
```

这项限制用于避免与逐字符标点转换产生冲突。原文列出的三种形式由此成为完整集合，而不是示例集合。

> 实现注记（2026-08-04）：`。.` 的链式转换（`。. → 。。`）在“前一个字符也是 `.`”的混合点序列中
> 不生效，否则 `.。.`、`。。.` 等输入会被破坏。`中文。` 后输入 `.` 仍正常得到 `中文。。`。

## 3. 配对、包裹与退格

必须保留现有：

* 开符号自动补全；
* 输入已有闭合符号时跳过；
* Tab 跳出；
* 选区包裹；
* `……`、`——` 整体退格。

光标位于空配对中间时，一次退格删除**`delimiterPairs()` 中全部现有配对**，不只限于 CJK 配对。

普通区域内，选区含任意 CJK 字符时，键盘和 IME 使用同一映射：

```text
( → （选区）
[ → 【选区】
" → “选区”
' → ‘选区’
< → <选区>
```

`<` 始终保持 ASCII，不转换为 `《》`。包裹后原内容继续保持选中。

## 4. 保护区

保护区包括：

````text
行内代码：闭合的 `...`、``...`` 等 code span
行内公式：闭合的 $...$
围栏代码块：``` 或 ~~~
块级公式：多行 $$ 块、单行 $$...$$
````

保护区内部禁用本次功能引入的全部改写：

* 半角标点转全角；
* 省略号转换；
* 破折号转换；
* CJK–ASCII 自动空格；
* `Alt+F` 格式整理；
* **CJK 选区的全角包裹映射**。

因此，在保护区内选中 `中文` 后输入 `(`：

```text
`中文`  → `(中文)`
$中文$   → $(中文)$
```

仍可使用既有 ASCII 配对和包裹功能，但不得自动改为 `（）`。行内代码和行内公式的**外部边界**仍可补空格。

## 5. 保护区语法

### 围栏代码块

* opener：至少 3 个相同的反引号或波浪线；
* closer：字符类型相同，长度不短于 opener；
* closer 后只能有空格或 Tab；
* `````oops`` 不得关闭围栏；
* 反引号围栏不能被波浪线关闭；
* 未闭合围栏保护至 EOF；
* 围栏内的 `$$` 不得改变公式状态。

### 块级公式

单行块公式：

```text
$$x+1$$
$$ x + y $$
```

只保护当前行，不切换多行状态。第二个未转义 `$$` 后只能有空白。

多行块公式：

```text
$$
内容
$$
```

分隔行除空白外只能包含 `$$`。未闭合时保护至 EOF。公式块内的 fence-looking 文本不得影响围栏状态。

```text
$$x+1
```

既不是合法单行公式，也不得开启多行公式状态。

### 行内代码

* 开闭 backtick run 长度必须完全相同；
* 不能从更长 run 中截取 closing；
* 不跨行；
* 未闭合时不构成保护区。

### 行内公式

* 只识别单个且未转义的 `$`；
* `$$` 只由块级公式规则处理；
* 不跨行；
* 未闭合时不构成保护区；
* `\$` 不得误判。

## 6. CJK–ASCII 自动空格

普通文本中：

```regex
([CJK])([A-Za-z0-9]) → $1 $2
([A-Za-z0-9])([CJK]) → $1 $2
```

例如：

```text
中文ABC         → 中文 ABC
ABC中文         → ABC 中文
中文123         → 中文 123
123中文         → 123 中文
使用Python3编程 → 使用 Python3 编程
```

ASCII 字母和数字属于同一类别：

```text
Python3 → 不变
GPT4    → 不变
v2      → 不变
```

不得：

* 重复添加已有空格；
* 删除或合并已有空格；
* 跨换行、标点或符号添加；
* 处理 CJK 与非 ASCII Unicode 字母；
* 在保护区内部添加；
* 因粘贴而自动添加。

## 7. 行内代码和公式外围空格

完整闭合的行内 span 内部保持原样，外部采用软空格规则：

```text
中文`code`中文     → 中文 `code` 中文
公式$x+1$成立      → 公式 $x+1$ 成立
测试`中文ABC`结束  → 测试 `中文ABC` 结束
```

已有空白或紧邻软分隔符时不添加：

```text
中文，`code`       → 不变
`code`，中文       → 不变
中文(`code`)文本   → 不变
```

固定软分隔符：

```text
全角：
， 。 、 ？ ！ ： ； “ ” ‘ ’
（ ） 【 】 《 》 「 」 『 』

半角：
, . ? ! : ; " ' - ( ) [ ] { }
```



## 8. 输入自动整理

自动整理只在以下时机执行：

* 普通键盘输入后；
* IME composition 完成并 commit 后。

不得在 IME composition 过程中改写文本或移动光标。

多字符 IME commit 必须检查：

* 提交片段内部的全部边界；
* 提交片段左外边界；
* 提交片段右外边界。

但只允许修改与本次提交范围有关的边界，不扫描其他位置。

以下操作不触发自动整理：

* 粘贴；
* 打开文档；
* 移动光标；
* 改变选区；
* 文档载入；
* 自动扫描整行或全文。

粘贴后只能显式执行 `Alt+F`。 

## 9. `Alt+F` 手动空格整理

ScratchEditor 命令：

```text
ID：formatSpacing
名称：整理选区或当前行格式
分类：编辑
默认快捷键：Alt+F
```

该命令**只整理空格**，不得批量转换标点、省略号、破折号或配对符号。

### 有选区

* 只处理严格位于选区内部的字符间边界；
* 不检查或修改选区两端与外部文本之间的边界；
* 保护区判断必须使用完整文档上下文；
* 保护区内容即使只被选中一部分也保持不变；
* 整理后继续选中整理后的逻辑内容；
* 保持正向／反向选择方向；
* 选区内部新增空格必须包含在新选区中。

### 无选区

* 只整理光标所在逻辑行；
* 不包含换行符；
* 不处理上下行；
* 当前行位于块级保护区内时不修改；
* 行内代码和公式内部不改，外围正常整理；
* 光标保持对应逻辑位置。

### 编辑事务

* 所有修改一次 Undo 完整恢复；
* Redo 一次重新应用；
* 没有修改时，不改变文本、光标、选区或 Undo 栈。

## 10. 实现与回归约束

* 实时输入和 `Alt+F` 必须共用同一套纯文本 parser／spacing planner；
* 保护区分析使用完整文档绝对坐标，授权范围才是局部范围；
* 坐标统一使用 Qt UTF-16 code-unit；
* 不依赖 MarkdownHighlighter；
* 每次操作最多读取一次全文、分析一次保护区；
* 先收集、去重插入点，再倒序写入；
* 不在候选循环中反复 `toPlainText()` 或扫描全文；
* Alt+F 的修改处于同一 edit block；
* 延迟回调不得使用已经移动的当前光标推测原输入位置；
* 不修改无关的 Markdown、列表、标题、查找替换、窗口、主题、配置或 AHK 功能；
* delimiter completion、Tab 跳出、Markdown toggle 等现有功能必须回归通过。

# 验收用例一：选区格式化

这是一个**反向、多行、截断两端、跨多种保护区**的用例。

## 原始文本

````text
前A中文ABC
前`中A文`后
前$中A文$后
```js
$$
中文ABC
```oops
ABC中文
```
$$
```
中文ABC
$$
$$x中文A$$
普通한글ABC123结束
尾ABC中文Z外
````

## 操作

1. 从最后一行 `尾ABC` 的 `C` 后开始拖动；
2. 反向选择到第一行 `前A` 的 `A` 后；
3. 即选区从第一行的 `中文ABC` 开始，到最后一行的 `尾ABC` 结束；
4. 执行 `Alt+F`。

## 期望结果

````text
前A中文 ABC
前 `中A文` 后
前 $中A文$ 后
```js
$$
中文ABC
```oops
ABC中文
```
$$
```
中文ABC
$$
$$x中文A$$
普通한글 ABC123 结束
尾 ABC中文Z外
````

必须同时满足：

* 第一行选区外的 `A|中` 边界不处理；
* 最后一行选区末端的 `C|中` 边界不处理；
* inline 内部 `中A文` 不变，外围补空格；
* fence 中的 `$$` 不污染公式状态；
* `````oops`` 不关闭 fence；
* block formula 中的 ``` 不污染围栏状态；
* 单行 `$$x中文A$$` 不变；
* 选区仍为**反向选择**，并覆盖整理后的完整逻辑内容；
  -一次 Undo 恢复原文和原选区，一次 Redo 恢复结果。

# 验收用例二：整行格式化

## 原始文本

```text
上一行ABC中文
$$x+1$$
甲A1乙，B2丙-日C3前`中A文`后$x中A$末$中文ABC
下一行中文ABC
```

第三行末尾的 `$中文ABC` 是**未闭合行内公式**。

## 操作

取消选区，把光标放在第三行任意位置，执行 `Alt+F`。

## 期望结果

```text
上一行ABC中文
$$x+1$$
甲 A1 乙，B2 丙-日 C3 前 `中A文` 后 $x中A$ 末$中文ABC
下一行中文ABC
```

必须同时满足：

* 上一行和下一行完全不变；
* 前一行单行块公式不吞掉第三行；
* `，B2`、`丙-日` 不跨符号加空格；
* `A1`、`B2`、`C3` 内部不拆分；
* 两个完整 inline span 内部不变，外围补空格；
* 未闭合 `$` 不构成保护区，且未闭合行内公式/代码段整体不参与格式化（2026-08-04 用户确认；
  旧期望 `末$中文 ABC` 已更正为 `末$中文ABC`）；
* 光标保持逻辑位置；
* 一次 Undo 恢复第三行全部修改。

# 验收用例三：输入自动格式化

按顺序执行，禁止用一次性设置文本代替真实 KeyPress／IME commit。

## A. 多字符 IME commit

初始：

```text
首|尾
```

在 `|` 处一次 IME commit：

```text
A中文B
```

期望：

```text
首 A 中文 B 尾
```

必须在 composition 期间保持不变，只在 commit 后一次完成：

* 左外边界 `首|A`；
* 内部 `A|中`；
* 内部 `文|B`；
* 右外边界 `B|尾`。

## B. 标点与省略号

分别在空白普通行真实输入：

```text
中,   → 中，
中--  → 中——
...   → ……
。。。 → ……
。。. → ……
.。.  → .。.
```

最后一项必须保持不变。

## C. 行内保护与外围空格

连续真实输入：

```text
前`中,文A--...`后
```

期望：

```text
前 `中,文A--...` 后
```

内部不得发生：

```text
,  → ，
A  前后加空格
-- → ——
... → ……
```

仅允许在完整 code span 外围补空格。

再对公式执行同样测试：

```text
前$中,文A--...$后
→ 前 $中,文A--...$ 后
```

## D. 保护区选区包裹

普通区域选中 `中文`，键盘输入 `(`：

```text
中文 → （中文）
```

行内代码内部选中 `中文`，键盘输入 `(`：

```text
`中文` → `(中文)`
```

分别再通过 IME commit `(` 重复两项，结果必须一致。

普通区域选中 `中文`，输入 `<`：

```text
中文 → <中文>
```

不得得到 `《中文》`。

## E. 粘贴负例

粘贴：

```text
中文ABC
```

必须保持：

```text
中文ABC
```

不能自动变为 `中文 ABC`；执行 `Alt+F` 后才允许整理。

## F. 全配对退格参数化检查

遍历 `delimiterPairs()` 中每一个现有 pair：

1. 生成空配对；
2. 将光标置于正中；
3. 按一次 Backspace；
4. 断言 opening 和 closing 同时删除；
5. 断言一次 Undo 恢复完整配对。

此项不得只抽测 `()` 或 `（）`。
