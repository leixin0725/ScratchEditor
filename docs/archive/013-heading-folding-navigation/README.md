# 标题折叠与导航实施记录

## 范围

- 为 Markdown ATX 1–6 级标题增加标准层级折叠，围栏代码块内的伪标题不参与结构分析。
- 标题左侧常驻显示折叠标记：展开状态为弱化色 `v`，折叠状态为强调色 `>`。
- 提供全部折叠/展开、所属标题折叠/展开和前后标题导航命令，并允许在命令面板中重绑快捷键。
- 导航或查找命中隐藏内容时，只展开使目标可见所必需的折叠路径。
- 折叠临时隐藏正文光标时停到可见标题末尾，并在用户未主动移动或编辑的前提下于展开后恢复。
- 前后标题导航使用先于文字绘制的 20% 强调色圆角底纹提示目标，停留 400ms 后淡出 300ms。

## 实现边界

- `HeadingFoldManager` 在一次文档 block 扫描中识别标题，使用栈在线性时间内计算同级/更高级边界，再统一应用 block 可见性。
- 位置统一使用 Qt UTF-16 code-unit 索引；文档变更通过队列任务合并重建，不在候选循环中重复读取全文。
- 折叠状态保留在当前文档 block 的会话内数据中，普通标题文本编辑不会丢失状态；载入新剪贴板、外部文件、历史项或测试文档时重置。不写入文件或 `settings.ini`。
- 折叠操作不改变文档文本和撤销栈；若插入光标将被隐藏，则保存 UTF-16 位置并移到最近的可见标题末尾。待目标重新可见时仅在用户未主动移动或编辑的情况下恢复。
- 标题导航高亮范围从首个 `#` 到最后一个非空白字符；QML 按视觉换行拆分紧贴文字的背景矩形，文本项以更高堆叠层绘制。
- block 可见性变化后显式刷新 Qt Quick `TextEdit` 的文档尺寸和全文文本节点；该 Qt 6.10.2 私有实现依赖集中在单一元对象调用处，不引入 `Qt6::QuickPrivate` 构建依赖。

- `window-ui` 隔离构建与回归通过：覆盖标记常驻、展开/折叠字形与配色、鼠标切换及光标恢复、导航高亮层级/范围/时序、折叠后滚动范围缩短，以及历史栏关闭且编辑器宽度不变时下一帧正文像素即时消失/恢复。
