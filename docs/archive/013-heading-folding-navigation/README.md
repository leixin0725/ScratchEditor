# 标题折叠与导航实施记录

## 范围

- 为 Markdown ATX 1–6 级标题增加标准层级折叠，围栏代码块内的伪标题不参与结构分析。
- 标题左侧常驻显示折叠标记：展开状态为弱化色 `v`，折叠状态为强调色 `>`。
- 提供全部折叠/展开、所属标题折叠/展开和前后标题导航命令，并允许在命令面板中重绑快捷键。
- 导航或查找命中隐藏内容时，只展开使目标可见所必需的折叠路径。

## 实现边界

- `HeadingFoldManager` 在一次文档 block 扫描中识别标题，使用栈在线性时间内计算同级/更高级边界，再统一应用 block 可见性。
- 位置统一使用 Qt UTF-16 code-unit 索引；文档变更通过队列任务合并重建，不在候选循环中重复读取全文。
- 折叠状态保留在当前文档 block 的会话内数据中，普通标题文本编辑不会丢失状态；载入新剪贴板、外部文件、历史项或测试文档时重置。不写入文件或 `settings.ini`。
- 折叠操作不改变文档文本和撤销栈；若光标将被隐藏，则移到最近的可见标题行首。

## 验证记录

- `editing` 隔离构建与回归通过：覆盖嵌套树、全部/本级折叠、光标安全、前后导航、祖先自动展开、围栏代码、标题编辑状态保留、查找命中与六组默认快捷键。
- `window-ui` 隔离构建与回归通过：覆盖标记常驻、展开/折叠字形与配色、鼠标切换及折叠后滚动范围缩短。
- 性能回归的冷启动、空闲 CPU/内存、动画、10 万字大文档、内部 IME 提交与 CJK/高 DPI 门槛均通过。系统级微软拼音注入首次及按规则重跑一次均未产生文本，已单独记录，未放宽断言。
