# 阶段 2：功能对等验收报告

验收时间：2026-08-01（Asia/Shanghai）

## 结论

阶段 2 已通过。Qt 版本现已具备深色界面、窗口几何记忆、按内容显示的滚动条、Escape 关闭并复制、焦点恢复和剪贴板异常保护。AHK 到 Qt 的常驻 IPC 与旧 AHK 编辑器回退路径只在隔离副本中接入；原始 `KeysRedirect.ahk` 未修改。

## 实现范围

- 使用 `QSettings` 保存窗口位置和大小；恢复时会按当前显示器可用区域校正，并保持 `500 x 320` 最小尺寸。
- 自绘深色滚动条仅在内容超出视口时显示，支持拖动。内容高度与滑块尺寸采用 60 ms 合并更新，滚动位置仍实时跟随。
- `Escape`、窗口关闭和 IPC `hide/toggle` 统一走剪贴板写回与隐藏路径。
- 隐藏后恢复此前的 Win32 前台窗口。
- 剪贴板读写采用短重试；读取失败时保留编辑器原内容并显示错误，写入失败时保持窗口和文本可见，不做静默丢失。
- 隔离副本 `integration/KeysRedirect.QtMigration.ahk` 提供 `UseQtScratchEditor` 开关。开关关闭或 Qt 启动/IPC 失败时调用完整保留的旧 `ToggleScratch()`。
