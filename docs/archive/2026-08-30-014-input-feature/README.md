# 剪贴板历史卡片拖入编辑区实施记录

## 范围

- 支持把剪贴板历史卡片拖到编辑区指定位置，插入该历史项的完整文本。
- 未超过系统拖动阈值时保留原有单击选择与双击载入行为。
- 成功放置后选中新插入的文本、关闭历史面板并把焦点交还编辑器。
- 编辑区外、历史面板遮挡区、Escape 或面板关闭都会取消操作，不修改正文和历史原项。

## 实现边界

- 拖动落点与编辑位置统一使用 Qt UTF-16 code-unit 索引，代理对前后的插入位置保持准确。
- 复用选区移动已有的落点光标、上下边缘自动滚动与 30ms 更新计时器，不引入系统剪贴板写入。
- 插入不替换拖动前的正文选区；插入文本及必要的有序列表编号维护归入同一个编辑块，可用一次 `Ctrl+Z` 完整撤销。
- 窄窗口覆盖布局中，被历史面板遮住的编辑区不接受放置；拖动准备和进行期间暂停面板悬停关闭计时，避免落点几何变化。
- 拖动测试 IPC 只在 `--test-mode` 隔离实例开放，生产命令门禁保持不变。

## 验证记录

- `editing` 隔离构建与全量回归通过，覆盖 UTF-16 代理对落点、保留原选区、编辑区外取消、有序列表维护和单次撤销。
- `window-ui` 隔离构建与全量回归通过，覆盖拖动阈值、面板几何稳定、Escape 取消、成功关闭与焦点恢复、窄窗口遮挡区拒绝放置。
- 剪贴板历史性能指标通过：交互到帧 p95 约 17.7ms；当次完整性能报告中的冷启动、内存、输入帧和 IME 环境基线项未通过，未为本功能放宽阈值。
