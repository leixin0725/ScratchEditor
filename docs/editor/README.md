# 编辑核心

命令由 `src/` 下的 `EditorCommandRegistry` 分发。位置与选区端点均按 Qt UTF-16 code unit 计数。一次编辑最多读取、分析全文各一次；批量变更先收集位置再倒序写入，保持线性复杂度。

## 命令与撤销边界

输入、删除、撤销和重做在编辑前通知 `InputAutoScroll` 记录视口，在原有事务
收尾位置请求布局后复核。该对象保存本轮保持状态、触边目标和诊断采样。
`Main.qml` 执行视口动画、手动滚动取消和动画结束后的保持释放。

`SelectionDrag` 管理正文选区移动、原生拖选和历史卡片拖入共用的边缘滚动定时器，
并负责鼠标抓取、落点和光标的清理。正文写入及其撤销事务仍由命令层执行。

`MarkdownLists` 根据文本和 UTF-16 范围识别列表、判断结构变化并计算编号替换。
编号序列按引用深度、缩进与分隔符区分。命令层决定何时修复，在当前编辑事务中
倒序写入替换，并维护文档快照和选区。

- 加粗、斜体和代码命令在无选区时按中英文自适应词边界处理相邻词语（连续中文整体
  包裹，中文标点切分，`英文+中文` 混合串只包裹光标所在侧的词）；在同类标记内部
  再次触发会取消对应格式，跨边界选区则只清理同类内部标记。
- 无选区时 `Ctrl+C` 复制光标所在整行（统一携带行尾换行符，末行也补上），`Ctrl+X` 剪切整行并让后续行补位、光标落在补位后一行的行首；撤销整行剪切会恢复剪切前的精确行内光标。无选区 `Ctrl+V` 在剪贴板以换行结尾时将其粘贴为当前行下方的新行（当前行原样保留，连续粘贴持续在下方堆叠；空文档、文档已以换行结尾时直接插入，不会产生前导空行），否则在光标处标准插入。有选区时这三个快捷键保持标准复制/剪切/替换行为。
- 撤销粘贴会恢复粘贴前的光标位置；粘贴曾替换选区时，同时恢复原选区及其方向。
- Tab 配对全角转换、CJK 按词删除、取消格式包裹、全部替换、清空、checkbox 和空列表退格的撤销会恢复操作前的光标位置；Tab 两阶段跳转中的撤销位置是触发转换前的闭符号前。路径拖入和有序列表转换在重做后再次撤销时也保持原编辑点。
- 三击鼠标选中光标所在逻辑整行（非末行含行尾换行符，末行不含），双击仍按词选择；三击后 `Ctrl+C` 复制整行内容（非末行含行尾换行符）。
- `Ctrl+左/右` 与 `Ctrl+Shift+左/右` 使用中英文自适应词边界移动/扩选：连续中文
  （含日文假名、韩文谚文与补充平面汉字）整体作为一个词一次跳过，中文标点
  （`，。！？、（）“”` 等）与空白、ASCII 标点一样作为分隔符被跳过，中文与相邻
  英文/数字边界正确切分；纯英文文本保持 Qt 原生按词移动行为。双击按词选择使用
  同一套边界：双击连续中文选中整串、双击英文单词选中该词、双击中文标点选中该标点；
  `Ctrl+Backspace` / `Ctrl+Delete` 按词删除与 Markdown 快捷键（`Ctrl+B`、`Ctrl+I`、
  `Ctrl+Alt+C`）的无选区按词包裹同样使用该边界。

## 标题与引用命令

- 标题设置、推进和循环命令不会主动选中当前标题行；光标会保持在正文中的相对位置。
- 空白行执行任一设置/循环标题命令会创建对应的 `# ` 到 `###### `；`Ctrl+Num+-` / `Ctrl+Num++` 只对已经是标题的行生效，普通文本行保持不变。任何标题再次执行同级命令都会取消标题并保留正文。光标紧跟在行首标题前缀后时，一次 Backspace 也会删除完整前缀。
- 标题折叠识别与语法高亮一致的 ATX 1–6 级标题，并忽略围栏内的伪标题。编辑保护、折叠与高亮共用围栏规则：行首可有空格或 Tab，连续至少三个反引号或波浪号开启围栏，后面可写语言名；关闭行须使用同一字符，长度至少等于开启行，余下只允许空格或 Tab。未闭合时保护延续到文末。可折叠标题左侧的 Lucide `chevron-down` / `chevron-right` 图标始终可见：展开时使用弱化色，折叠时使用界面强调色。折叠或展开后编辑区会在下一渲染帧立即刷新，无需改变窗口布局。折叠一个标题会隐藏其正文和下属子标题，直到下一个同级或更高级标题；“折叠所有标题”保留文档顶层大纲可见。若插入光标位于将被隐藏的正文，折叠后会临时落到最近可见标题的行末；用户未主动移动或编辑时，重新展开会恢复折叠前的正文位置。
- `Ctrl+Up` / `Ctrl+Down` 按文档顺序跳到上一个/下一个标题行首；目标被折叠时自动展开必要的祖先标题。每次成功跳转会在标题实际文字范围（包含 `#`）下方显示 20% 不透明度的强调色圆角高亮，停留 400ms 后用 300ms 淡出；关闭动画时停留后立即消失。每次成功跳转后还会尝试滚动，使标题首行居于编辑区上 1/3 分点：与翻页/自动滚动共用约 160ms 轻量平滑动画（关闭动画时瞬时到位），跳转期间抑制瞬时贴边跟随以保证整段跳转是单一平滑移动，目标标题刚从折叠中展开时在布局落定后定位。查找命中折叠正文时也会自动展开对应路径。折叠状态只属于当前编辑会话，载入新内容时重置，不写入用户配置或文件。
- 引用命令在空行生成 `> `，执行后不会保留自动选区。逻辑行第 0 列输入 `>` 会自动补为空格结尾的
  `> `；输入全角 `》` 会转换为 `> `。键盘输入和 IME 提交行为一致，转换与补空格可一次撤销；
  行中、缩进后、有选区或围栏代码块内保持字面输入。

## 配对与输入法

- 无选区时，`Tab` 优先处理括号、引号、反引号或 Markdown 强调标记：内容中间先移动到闭标记前，再按一次才越过闭标记；已紧贴闭标记（含空配对）时直接跳出。第一阶段只移动光标，含 CJK 的半角配对仅在真正跳出时按现有规则转换。未命中配对时，无论光标位于行内何处，都在行首增加 4 个空格；有选区时保持原有行缩进。`Shift+Tab` 减少一级缩进。
  Tab 配对搜索限定当前行，忽略前接奇数个连续反斜杠的括号、引号、反引号及强调标记；偶数个反斜杠不影响配对，引号内部仍允许嵌套。
- 括号、引号、行内代码与围栏代码支持自动补全，包含半角、全角及常用中文成对符号。
  光标位于行中时，引号类符号（`` ` ``、`"`、`'`、`“”`、`‘’` 等）只输入单个开符号；
  光标位于列 0 且右侧已有正文时，单双引号同样只输入开符号（反引号仍保留围栏补全），
  输入闭符号完成包裹后再收尾：包裹内容含中文时 ASCII 引号转为全角；全角引号包裹
  会在与相邻中文/字母数字之间补自动空格（如 `中文 “内容” 结束`），纯 ASCII 引号包裹保持原样；
  当前行已有同类未闭合引号时，在行尾输入引号会优先补单个闭符号，不触发新的一对自动补全；
  检测不跨行，并忽略反斜杠转义的引号；
  行尾的 CJK 引号自动补全同样补空格（如 `中文` 后输入 `"` 得到 `中文 “”`）；
  中文输入法直接提交 `“` / `‘` 时同样完成配对与自动空格，随后提交 `”` / `’` 会越过已有闭符号；
  若输入法因内部状态在行尾提交孤立的 `”` / `’`（光标后允许只有空格或 Tab），则视作对应开引号
  并生成新配对；当前行存在同类未闭合开引号时仍优先完成闭合；
  先输闭符号、再补开符号完成包裹时，边界自动空格行为与先开后闭一致。
- 行首（列 0）连续输入三个反引号自动补全围栏代码块：光标后本行仍有文字时，闭合围栏单独成行、
  后续文字移到其下一行（如 `|测试文字` 输入后得到 `` ``` ``、`` ``` ``、`测试文字` 三行）；
  光标后无文字时不额外加空行。行中、行末和带缩进的行首不触发围栏自动补全。
- 自动空格与触发它的输入动作合并为一次撤销（一次 `Ctrl+Z` 同时撤销输入与空格整理）。
- ASCII 片段后的右边界自动空格是临时的：光标停在空格前，若下一次输入以中文等 CJK
  字符结尾，该空格会随本次输入一并清除（如 `中文 abc` 后输入 `新的中文` 得到
  `中文 abc 新的中文`，而不是 `中文 abc 新的中文 中文`）；若后续仍是 ASCII 输入则保留。
- 中文标点自动转换：在 CJK 字符或全角 `，。：；？！）` 之后输入半角 `, . : ; ? ! )` 自动转为对应全角，`( [ " '` 生成全角配对；半角 `, . : ; ? !` 后连续输入两个空格同样转为全角并删除两个空格；连续输入 `...`、`。。。` 或 `。。.` 会生成 `……`，其中 `。。。` 同时支持中文输入法逐个提交。除该全角省略号规则外，普通 IME 提交与粘贴不执行标点转换；行内代码、公式、围栏等保护区内均不转换。Tab 跳出 `() [] " '` 半角配对时，若内容含 CJK 则整对转为全角 `（）【】“”‘’`（保护区同样不转换）。
- `·`（U+00B7 中间点）空格后输入时触发反引号转换：删除空格与 `·` 后生成反引号对
  `` `|` `` 并补自动空格；连续输入两个 `·`（紧贴字符）同样生成反引号对，光标居中并按
  边界规则补两侧自动空格；完全空行上生成反引号对后再输入 `·` 会升级为大代码块围栏；
  有选区时输入 `·` 等价于输入 `` ` ``，用反引号对包裹选区并触发自动空格；
  围栏代码块内不触发上述转换（一次 `Ctrl+Z` 撤销）。
- 空 Markdown 标记对与空围栏代码可用一次退格整体删除；`……`、`——` 也支持整体退格删除，空行输入 `-` 会自动补为 `- `。

## 列表与换行

- Enter 自动接续无序列表、有序列表和任务复选框（新任务重置为未勾选）；有序列表在增删换行、整行删除/剪切、选区替换、粘贴、拖动和缩进变化后会自动维护同层编号。Tab 新建的嵌套层从 `1.` 开始，接入已有同层子列表时继续其编号，Shift+Tab 回到父层后重新加入父层序列；其他连续列表以首项编号为起点，手工修改首项可更换起点。嵌套空列表项再次 Enter 会只退出一级缩进、跟随父层列表格式，并在有序父层中接续编号；孤立缩进项同样逐级退出但保留原标记。退到顶层后再次 Enter 才会删除列表头并保留空行，Backspace 则会整行删除并回到上一行末尾。列表续行、退层与撤销/重做会保持编辑点光标，不会跳回文档开头。
- 命令面板的“转换为有序列表”处理选区实际覆盖的整行；无选区时处理当前行。它只转换普通
  `-`、`+`、`*` 无序项，不修改任务项、普通文本或围栏代码。纯无序区域从 `1.` 开始；选区
  同时包含有序项时，会按缩进和引用层级向外找到完整列表，以最上方有序段的首项编号及
  `.` / `)` 格式为锚点，把选中的无序项接入后按文档顺序重编号。选中的无序项可桥接同一
  连续区域内格式不同的有序段；未选中的无序项、任务项、普通文本、空行和围栏形成边界，
  不同区域及嵌套层级分别编号。执行后选中全部处理范围；文本转换和选区外重编号可用一次
  `Ctrl+Z` 撤销并恢复原选区。若只有有序项，则只整理并扩选其完整列表；纯扩选不写入撤销栈。
- 引用行有内容时，Enter 自动把完整引用头接续到下一行；只有引用头的空引用行按 Enter 会逐次退出最内层引用，直至保留普通空行。`Shift+Enter` 即使在空引用行也会保留全部层级并接续引用；引用内列表的普通 Enter 优先接续列表，`Shift+Enter` 只接续引用头。非引用列表中的 `Shift+Enter`、有选区、光标位于引用头内部及围栏代码块内仍为普通换行。
- 光标紧跟在引用头后时，一次 Backspace 删除完整的最内层 `> `；多层引用逐层删除，围栏代码块内保持普通退格。
- `Ctrl+L` 切换光标所在行的 checkbox 勾选状态；非 checkbox 行会转换为未勾选任务，并保留已有列表编号、缩进和多层引用前缀。
