# 2026-08-06 右上角状态面板

## 功能

- 顶栏右侧从固定快捷键提示改为动态状态显示：正常时显示字数统计（`共 N 字 · M 汉字`；有选区时显示 `A / N 字 · B / M 汉字`），出错时仍显示红色错误文本。
- 鼠标悬停在顶栏状态文字上展开小面板：
  - 正常态：逐行显示当前模式（临时编辑器 / 外部提示词编辑器）的核心快捷键提示（含命令面板、设置快捷键，显示当前生效值并随改键刷新），以及字数统计；
  - 错误态：显示红色错误全文，点击可复制到剪贴板，复制成功后面板保持展开并显示“已复制”，鼠标移开后自动收起。
- 面板位于状态文字下方右对齐，宽度、字号与悬停/收起延迟均可配置。

## 配置（settings.ini）

| 键 | 默认值 | 合法范围 |
|---|---:|---:|
| `statusPanel/fontSize` | 10 | 9–24 |
| `statusPanel/showDelayMs` | 300 | 0–2000 |
| `statusPanel/hideDelayMs` | 250 | 0–3000 |
| `statusPanel/maxWidth` | 360 | 200–800 |

设置页新增“状态面板”分组，可编辑上述四项；“恢复默认”会同时重置外观与状态面板设置。

## 实现说明

- 快捷键提示条目集中定义于 `src/statuspanelhints.h`（shortcut + label 结构化数据），后续扩展提示只需增改该列表；命令面板/设置条目接收当前生效快捷键（来自命令注册表），用户改键或清空后提示随之更新或隐藏。
- “字”按 Qt UTF-16 code-unit 长度计算（`characterCount - 1` 与选区两端差值，语义不变）；“汉字”按 Unicode 码点统计汉字表意字符（含扩展 A、统一表意、兼容表意与补充平面扩展 B–H，不含假名、谚文与标点），每次文本变化进行一次全文读取与线性扫描（符合编辑核心“每次编辑最多一次全文读取、一次分析”的约束）。
- 面板颜色、圆角与动画跟随现有主题与 `transitionDuration`，不新增可配置项。
