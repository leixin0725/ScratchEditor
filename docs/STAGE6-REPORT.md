## AHK 实现

- 移除 `ScratchGui`、原生 `Gui(...)`、缩放命中、拖动、DWM 绘制、滚动条和关闭回写等旧 GUI 代码；相关引用计数为 0。
- 保留 `ScrollLock::F14` 基础映射，并由 `ScrollLock::ToggleScratchEditor()` 调用 Qt。
- AHK 启动时通过单次计时器预热 `ScratchEditor.exe --background`。
- 默认管道仍为 `ScratchEditor.Stage1.v1`；默认程序路径仍为
  `D:\_Dev\ScratchEditor\build\stage4\ScratchEditor.exe`，没有移动部署目录。
- 冷启动时使用双向 `status` 请求等待真实 `ready=true`，之后再建立持久写管道，避免“管道已创建但 QML 尚未就绪”的竞态。
- 正常热路径沿用持久管道发送 `toggle`；写入失败时关闭失效句柄并尝试一次受控启动。
- 失败回退只显示 2.5 秒提示，生产回退函数中没有 `A_Clipboard :=`，因此不会破坏文本、图片或文件等现有剪贴板格式。
- 测试入口必须同时提供专用环境变量和命令行参数，正常启动不会进入测试分支。
