# Feature Specification: 剪贴板历史

**Feature Branch**: `004`

**Created**: 2026-08-09

**Status**: Draft

**Input**: User description: "为 ScratchEditor 增加类似 Windows 原生历史体验的纯文本剪贴板监听、内部存储、查看、回溯和编辑功能，并集成到现有临时编辑器左侧。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 自动记录并浏览剪贴板历史 (Priority: P1)

作为经常复制文本的用户，我希望 ScratchEditor 在后台记录后续复制的文本，并在现有临时编辑器左侧提供按时间倒序排列的历史栏，以便找回已被新复制内容覆盖的文本。

**Why this priority**: 自动记录和可见列表构成剪贴板历史的最小可用价值；没有这部分，回溯和编辑都无数据可用。

**Independent Test**: 在监听已启动后依次复制多段文本，打开编辑器并展开左侧栏，能够看到最新内容位于最上方，退出并重新启动后仍能看到有效历史。

**Acceptance Scenarios**:

1. **Given** 常驻编辑器已经开始监听且历史为空，**When** 用户复制一段合规纯文本，**Then** 该文本在 500ms 内成为历史首项。
2. **Given** 历史中已有若干记录，**When** 用户复制新的不同文本，**Then** 新记录出现在首位，既有记录保持原有相对顺序。
3. **Given** 历史已加密保存，**When** 同一 Windows 用户重新启动常驻编辑器，**Then** 所有未被淘汰或删除的有效记录按原顺序恢复。
4. **Given** 来源应用明确禁止内容进入剪贴板历史，**When** 该内容进入系统剪贴板，**Then** ScratchEditor 不得保存或展示它。

---

### User Story 2 - 回溯并编辑历史文本 (Priority: P2)

作为用户，我希望选择一条旧记录并把它载入当前编辑区，以便直接复用原文或修改后再使用，同时保留原始历史记录。

**Why this priority**: 回溯和编辑把被动历史转化为可复用内容，是相较普通日志列表的核心用户价值。

**Independent Test**: 选中任一旧记录并通过双击或 Enter 载入，修改后用现有保存或发送动作完成操作，原记录仍存在且修改结果成为最新记录。

**Acceptance Scenarios**:

1. **Given** 历史栏已展开且某条记录被单击选中，**When** 用户按 Enter 或双击该记录，**Then** 文本载入主编辑区，历史栏收起，输入焦点进入编辑器。
2. **Given** 主编辑区存在未提交修改，**When** 用户请求载入另一条历史记录，**Then** 系统先要求确认；只有确认后才覆盖当前缓冲区。
3. **Given** 一条历史记录已载入并被修改，**When** 用户成功回写剪贴板或发送文本，**Then** 原历史项保持不变，修改后的文本作为最新记录加入。
4. **Given** 一条历史记录已载入，**When** 用户执行放弃关闭，**Then** 不新增历史、不修改系统剪贴板且原历史项保持不变。

---

### User Story 3 - 快速定位并适配不同窗口尺寸 (Priority: P3)

作为拥有较多历史记录或使用不同窗口尺寸的用户，我希望搜索历史文本，并在展开历史栏时始终保留可用的正文编辑空间。

**Why this priority**: 100 条记录需要有效定位方式，响应式布局则避免历史功能破坏现有轻量编辑体验。

**Independent Test**: 在包含 100 条记录的历史中输入查询并定位目标；分别使用最小窗口和宽窗口展开历史栏，正文可见宽度始终符合下限。

**Acceptance Scenarios**:

1. **Given** 历史中存在包含不同大小写关键词的记录，**When** 用户在搜索框输入关键词，**Then** 列表即时显示所有不区分大小写的子串匹配项，并保持最新优先。
2. **Given** 窗口足够宽，**When** 历史栏展开，**Then** 历史栏挤压正文，但正文可见宽度不少于 320px。
3. **Given** 挤压会使正文可见宽度低于 320px，**When** 历史栏展开，**Then** 自动改为覆盖正文，窗口尺寸和正文布局宽度不被进一步压缩。
4. **Given** 历史栏通过命令面板打开并获得焦点，**When** 用户使用方向键和 Enter，**Then** 可以不依赖鼠标选择并载入记录。

---

### User Story 4 - 管理本地历史 (Priority: P4)

作为注重隐私和整洁的用户，我希望删除单条记录或清空内部历史，同时不影响当前系统剪贴板和正在编辑的文本。

**Why this priority**: 本地长期保存的数据必须由用户可控，但管理功能不影响记录、查看和回溯的核心闭环。

**Independent Test**: 删除单条记录并确认清空全部历史，验证记录被移除，同时系统剪贴板和主编辑缓冲区逐字保持不变。

**Acceptance Scenarios**:

1. **Given** 历史中有多条记录，**When** 用户删除其中一条，**Then** 仅该内部记录消失，当前系统剪贴板不变。
2. **Given** 历史非空，**When** 用户选择清空全部并确认，**Then** 所有内部记录被删除，当前系统剪贴板和编辑缓冲区不变。
3. **Given** 清空确认正在显示，**When** 用户取消，**Then** 历史、剪贴板和编辑缓冲区均不改变。

### Edge Cases

- 常驻进程开始监听时系统剪贴板已经包含文本：该启动前内容不导入历史，只记录监听开始后的变化。
- 剪贴板为空、没有可用纯文本表示或纯文本载荷超过 1 MiB：忽略该次变化，不截断内容，也不修改系统剪贴板；若同一剪贴板项还包含 HTML、图片等格式，只存储其纯文本表示。
- 剪贴板暂时被其他程序占用：进行有限重试；仍无法读取时保留已有历史并显示可见错误。
- 新文本与任一既有记录完全相同：不新增副本，刷新该记录时间并移到首位；空白和换行差异视为不同文本。
- 加入第 101 条不同文本：自动淘汰当时最旧的一条记录。
- ScratchEditor 自己成功回写或发送文本：只记录一次，不因内部写入和监听通知产生重复项。
- 加密历史无法读取、验证失败或无法写入：不得用空数据覆盖原文件；历史功能进入可见错误状态，当前编辑功能继续可用。
- 用户删除已经载入编辑区的历史项：列表中的记录被删除，但已载入的编辑缓冲区不改变。
- 搜索结果在外部复制导致历史置顶后发生变化：保持有效选择；若原选择已不存在，则选择最接近的可见项。
- 外部文件编辑模式：不显示历史栏，不读取或修改内部历史，继续保持其绕过剪贴板的既有契约。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 在常驻编辑器开始监听后持续观察系统剪贴板变化，即使主窗口处于隐藏状态也不得停止；启动前已有内容不得被追溯导入。
- **FR-002**: 系统 MUST 只存储剪贴板项的非空纯文本表示，且单条文本的 UTF-8 载荷不得超过 1 MiB；同一项目包含 HTML、图片或其他格式时不得保存这些附加格式，没有纯文本表示、空文本和超限文本 MUST 被忽略且不得截断。
- **FR-003**: 系统 MUST 识别并尊重来源内容禁止进入剪贴板历史或监控处理的系统标记，被排除内容不得进入内存列表或持久存储。
- **FR-004**: 系统 MUST 将历史加密保存在本机，使其只能由创建数据的同一 Windows 用户正常读取；不得上传、同步或依赖 Windows 原生剪贴板历史。
- **FR-005**: 系统 MUST 最多保留 100 条不同文本。完全相同的文本 MUST 全局去重、刷新复制时间并移至首位；新增不同文本超过上限时 MUST 淘汰最旧记录。
- **FR-006**: 系统 MUST 将 ScratchEditor 自身成功回写或发送的文本按同一规则记录一次；失败或被放弃的编辑不得新增或重排历史。
- **FR-007**: 普通剪贴板编辑模式 MUST 在窗口左侧显示默认折叠的单列历史栏；外部文件编辑模式 MUST 不显示或访问该历史栏。
- **FR-008**: 折叠历史栏 MUST 保留 12px 的左侧触发边缘，并以不拦截窗口拖动或 resize 的 hover 感应覆盖窗口左框。指针从外侧或内侧进入该区域并持续 100ms 后 MUST 展开；指针无按键地快速向左越出窗口有效纵向范围时 MUST 立即展开；离开触发区域和面板 250ms 后 MUST 收起。通过命令打开并持有键盘焦点时不得因指针离开而立即收起。
- **FR-009**: 历史栏展开宽度 MUST 按 `clamp(窗口宽度 / 3, 200px, 360px)` 计算。系统 MUST 优先挤压正文；若编辑内容区扣除历史栏后可见宽度将低于 320px，则 MUST 自动切换为覆盖模式。
- **FR-010**: 系统 MUST 提供“打开剪贴板历史”可配置命令并将其列入现有命令面板；该命令初始 MUST 不绑定默认快捷键。
- **FR-011**: 历史列表 MUST 按复制时间从新到旧排列。每项 MUST 显示多行文本预览、复制时间和与主编辑器一致的字数，不得显示推测的来源应用。
- **FR-012**: 展开的历史栏 MUST 提供搜索框，按完整历史文本执行不区分大小写的子串匹配；搜索结果 MUST 保持时间倒序，并支持方向键选择。
- **FR-013**: 单击历史项 MUST 只改变选择。双击或按 Enter MUST 请求把选中记录载入主编辑区。
- **FR-014**: 主编辑区存在未提交修改时，系统 MUST 在载入历史项前请求确认；取消 MUST 保留当前文本、选择和历史栏状态。
- **FR-015**: 载入成功后，系统 MUST 收起历史栏并聚焦主编辑器；既有回写、发送和放弃快捷键语义 MUST 保持不变。
- **FR-016**: 历史项 MUST 保持不可变。载入后产生的修改只有在成功回写或发送后才能按去重规则成为最新历史；原历史文本不得被原地覆盖。
- **FR-017**: 用户 MUST 能删除单条历史，并在确认后清空全部历史。两种操作均不得修改系统剪贴板、当前编辑缓冲区或其他用户设置。
- **FR-018**: 监听、读取、解密或保存失败时，系统 MUST 保留最后已知有效历史和当前编辑内容，显示可理解的错误，并避免用空历史覆盖可能可恢复的数据。
- **FR-019**: 历史栏动画 MUST 遵循现有动画启用状态；动画关闭时，展开、收起和响应式模式切换 MUST 立即完成。

### Key Entities

- **Clipboard History Item**: 一条不可变的纯文本历史记录，包含完整文本、最近复制时间和字数；文本本身决定全局去重身份。
- **Clipboard History Collection**: 当前用户的有序本地记录集合，最多包含 100 个不同项目，负责最新优先排序、淘汰和持久化状态。
- **History Panel State**: 当前窗口会话中的折叠/展开模式、搜索文本、可见结果和选中项；它不改变历史项目内容。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 在剪贴板可正常读取时，95% 的合规文本复制在 500ms 内出现在已展开的历史列表首位。
- **SC-002**: 对 100 条上限历史执行展开、筛选或重新排序时，95% 的操作在 100ms 内向用户显示完整结果。
- **SC-004**: 连续 10 次正常关闭和重新启动后，所有未删除、未淘汰的有效历史记录均完整恢复，文本和顺序无差异。
- **SC-005**: 带系统历史排除标记的测试内容进入内部历史的比例为 0%。
- **SC-006**: 在所有窗口宽度下，挤压模式中的正文可见宽度始终不少于 320px；不满足时 100% 自动使用覆盖模式。
- **SC-007**: 逐条删除、取消清空和确认清空的全部验收场景中，系统剪贴板及当前编辑缓冲区的意外变化次数为 0。
- **SC-008**: 在剪贴板占用、持久数据损坏和保存失败测试中，既有有效历史被空数据覆盖的次数为 0，主编辑器仍可继续使用。

## Assumptions

- 目标用户是当前 Windows 桌面会话中的单一用户，不需要跨用户、跨设备或云端同步。
- 当前 AHK 的 `ScrollLock` / `Win+F` 全局入口及生产 IPC 契约保持不变；本功能不接管系统 `Win+V`。
- 文本相同判断保留所有原始字符、空白和换行，不执行大小写、Unicode 或换行标准化。
- 搜索条件在当前窗口可见期间保留，窗口隐藏后清空；历史栏每次重新显示窗口时默认折叠。
- 清空全部需要确认，逐条删除无需确认；首版不提供撤销删除、固定项、暂停监听或来源应用黑名单。
- 历史数据不可由其他 Windows 用户读取；用户凭据变化导致历史无法解密时，按不可恢复数据处理，但不得自动覆盖原数据。
- 开发和验证使用完全隔离的剪贴板与历史存储，不读取、修改、快照或清理用户的真实系统剪贴板和生产历史。
